# 20 张 RAW 人工验收表

每张 RAW 生成候选 A、B 和原图对照。机器项用于筛查，审美项必须由评审填写。

| 字段 | 评分或填写 | 类型 |
|---|---|---|
| 图像 ID / 场景 / 输出尺寸 | 文本 | 记录 |
| 技术正确性 | 1-5；解码、几何、色彩或导出异常 | 机器筛查 + 人工确认 |
| 曝光与高光 | 1-5；保留纹理、阴影层次 | 机器筛查 + 人工判断 |
| 白平衡与肤色 | 1-5；中性色、肤色可信度 | 人工为主 |
| 噪声与纹理 | 1-5；噪点、蜡感、细节 | 人工为主 |
| 锐化与伪影 | 1-5；边缘、光晕、振铃 | 机器筛查 + 人工确认 |
| 主体表现 | 1-5；可读性和背景竞争 | 人工 |
| 是否需要大幅返工 | 否 / 是；说明原因 | 人工 |
| A/B 选择 | A / B / 平局 / 两者都退回 | 人工 |
| 用户自由反馈 | 文本 | 人工 |

机器筛查：记录直方图端点/高光警告、导出错误、明显色偏候选、100% 边缘伪影候选。机器检查不得替代“肤色自然”“氛围保留”“风格合适”判断。

汇总规则：每张填写一次；任何一项 1-2 分或“需要大幅返工”都进入复盘。对 A/B 平局和两者退回，记录具体失败信号并关联规则 ID。
