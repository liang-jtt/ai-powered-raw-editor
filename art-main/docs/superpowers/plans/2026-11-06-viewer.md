then direct RAW render. No post-edit review, yellow-cast instructions, or style preset.

- [x] Test independent viewer aggregation, partial failure, and future rectangle forwarding.

- [x] Attach viewer data before AI generation. Default mode uses viewer measurements without legacy histogram processing recommendations.
- [x] Verify build and tests; run DSC02691.ARW using the configured provider and a single generation; render and prepare the actual result for display.

Regional detection is not automatic; optional rectangle coordinates remain part of the viewer interface.
