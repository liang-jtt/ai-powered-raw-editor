# 两个独立审美评分模块

用户已确认：封装 ICAA 与 HPSv3，提供数据接口；沿用前一模块的独立部署原则，不修改 AI-PP3 与颜色检测模块。

## 设计

- `icaa/cli.py`、`hpsv3/cli.py` 为两个独立 JSON 标准输入/输出入口。共同协议提供 `status`、`score`、`rank`。同一请求内处理多张图片，避免每张重新加载模型。
- `aesthetic_assessors/` 仅共享协议、图片预处理与结果校验，两个模型各有独立适配器与依赖说明。Python 类支持在一个进程中复用已加载模型。
- ICAA 使用官方 ICAA17K DAT 源码与匹配的色彩审美训练权重。遵循官方评测 Resize(224,224)、ImageNet normalize，取输出第 2 维作为色彩分，第 1 维单独报告为整体分。strict=True 加载权重，不接受仅骨干预训练作为完整模型。
- HPSv3 调用官方 `HPSv3RewardInferencer`，每个候选使用相同 prompt，按官方用法取输出 mu。配置要求本地完整基础模型与 checkpoint，运行接口默认离线，避免一次请求隐式下载大型模型。
- 排名是同一后端、同一配置、同一请求中的相对排名；原始分数不跨模型混合，不假装个人偏好或置信度。并列保留，不设审美合格阈值。
- 缺依赖/资产、非法输入、加载失败、非有限输出均返回 JSON 错误；不以随机模型或启发式数据充当模型分数。
